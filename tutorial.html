Busque, baixe, extraia e visualize dados de Índice de Calor para o Semiárido Brasileiro.

Instalação

# Instale pelo GitHub # install.packages("remotes") remotes::install_github("antcneto/heatindexbr") library(heatindexbr)

Busca de municípios

Os nomes de municípios seguem o padrão IBGE: maiúsculas sem acentos. Use hi_search() para encontrar o nome correto:

hi_search("Mossoro", state = "RN") hi_search("Campina Grande", state = "PB")
Use sempre o valor da coluna name_muni retornado por hi_search() nas chamadas seguintes. Por exemplo, use MOSSORO, não Mossoró. Isso segue o padrão de nomenclatura do IBGE.

Extração do Índice de Calor por município

hi_municipality() baixa a tabela municipal na primeira chamada (~29 MB, armazenada em cache) e retorna estatísticas com classificação NOAA. Nenhum download de raster é necessário.

# Janeiro às 15h hora local hi_municipality("MOSSORO", state = "RN", month = 1, hour_local = 15) # Todos os meses e horas hi_municipality("MOSSORO", state = "RN")

Download e visualização do raster

Download no primeiro uso: hi_download() baixa o stack completo de médias climatológicas (~1,6 GB) do Zenodo na primeira chamada. Dependendo da sua conexão, isso pode levar de alguns minutos a até 30 minutos. Isso acontece apenas uma vez; todas as chamadas seguintes leem do cache local instantaneamente. Se você só precisa de estatísticas municipais, use hi_municipality() com source = 'table', que baixa um arquivo de 29 MB e nunca toca no raster.
# Banda única: janeiro às 15h local r <- hi_download(month = 1, hour_local = 15) # Todas as horas de julho (raster com 24 bandas) r_julho <- hi_download(month = 7) # Stack completo de 288 bandas r_stack <- hi_download() # Visualizar hi_plot(r, title = "Índice de Calor, Janeiro, 15h local")

As horas são especificadas em hora local (UTC-3) e convertidas para UTC automaticamente. Por exemplo, hour_local = 15 recupera a banda armazenada às 18h UTC.

Extração para polígono personalizado

Use hi_shape() com qualquer objeto sf:

library(sf) minha_area <- st_read("minha_area.gpkg") resultado <- hi_shape(minha_area, month = 1, hour_local = 15) resultado$stats # data.frame com media, min, max, noaa_class resultado$raster # SpatRaster recortado

Exposição populacional por classe NOAA

hi_exposure() calcula a população exposta a cada classe NOAA do Índice de Calor para um dado mês e hora local. Baixa a tabela municipal com dados populacionais dos Censos IBGE de 2000, 2010 e 2022 (~35 MB, em cache após o primeiro uso).

# Total do Semiárido em janeiro às 15h hi_exposure(month = 1, hour_local = 15, by = "semiarid") # Por estado hi_exposure(month = 1, hour_local = 15, by = "state") # Por município (padrão) hi_exposure(month = 7, hour_local = 12, by = "municipality") # Usando pesos do Censo 2000 hi_exposure(month = 1, hour_local = 15, census_year = 2000, by = "semiarid")

Produto sinótico de 2025 (v0.1.0)

O produto original de 2025 permanece disponível via argumento product para análises especificamente sobre o ano de 2025:

r_2025 <- hi_download(product = "synoptic_2025", hour_local = 15) hi_municipality("MOSSORO", state = "RN", product = "synoptic_2025", hour_local = 15)

citation("heatindexbr")
