hi_download()

Baixa as médias climatológicas do Índice de Calor do Zenodo e as armazena em cache local. Na primeira chamada, baixa o stack completo de 288 bandas (~1,6 GB). Chamadas seguintes leem do cache e extraem as bandas solicitadas em memória.Baixa as médias climatológicas do Índice de Calor do Zenodo e as armazena em cache local. Na primeira chamada, baixa o stack completo de 288 bandas (~1,6 GB). Chamadas seguintes leem do cache e extraem as bandas solicitadas em memória.

ArgumentosArgumentos

ArgumentoArgumentoTipoTipoPadrãoPadrãoDescriçãoDescrição
productchr"climatology"Identificador do produto: climatology (2000-2025) ou synoptic_2025 (v0.1.0).
monthintNULLMês (1-12). Se NULL, todos os meses são retornados.Mês (1-12). Se NULL, todos os meses são retornados.
hour_localint / chrNULLHora local UTC-3 (0-23) ou caractere como "15h". Se NULL, todas as 24 horas são retornadas.
cache_dirchrNULLDiretório de cache. Usa o cache padrão do pacote.Diretório de cache. Usa o cache padrão do pacote.
overwritelglFALSEForça novo download mesmo que o arquivo já esteja em cache.Força novo download mesmo que o arquivo já esteja em cache.
quietlglFALSESuprime mensagens de progresso do download.Suprime mensagens de progresso do download.

RetornaRetorna

Um objeto SpatRaster (pacote terra). Banda única quando month e hour_local são especificados; múltiplas bandas caso contrário.

ExemplosExemplos

# Banda única: janeiro às 15h local r <- hi_download(month = 1, hour_local = 15) # Todas as horas de julho (24 bandas) r_julho <- hi_download(month = 7) # Stack completo de 288 bandas r_stack <- hi_download() # Produto sinótico 2025 (v0.1.0) r_2025 <- hi_download(product = "synoptic_2025", hour_local = 15)
hi_municipality()

Extrai estatísticas do Índice de Calor para um ou mais municípios pelo nome. Por padrão lê da tabela municipal pré-computada (~29 MB), muito mais rápido que a extração raster e sem necessidade de baixar o stack completo.Extrai estatísticas do Índice de Calor para um ou mais municípios pelo nome. Por padrão lê da tabela municipal pré-computada (~29 MB), muito mais rápido que a extração raster e sem necessidade de baixar o stack completo.

ArgumentosArgumentos

ArgumentoArgumentoTipoTipoPadrãoPadrãoDescriçãoDescrição
municipalitychrNome do município em maiúsculas sem acentos (padrão IBGE). Use hi_search() para encontrar o nome correto.
statechrNULLSigla do estado com duas letras (ex.: "RN"). Recomendado quando o nome não é único.
monthintNULLMês (1-12). Se NULL, os 12 meses são retornados.Mês (1-12). Se NULL, os 12 meses são retornados.
hour_localint / chrNULLHora local (0-23). Se NULL, as 24 horas são retornadas.Hora local (0-23). Se NULL, as 24 horas são retornadas.
productchr"climatology""climatology" ou "synoptic_2025".
sourcechr"table""table" (rápido) ou "raster" (extrai do stack).
return_rasterlglFALSESe TRUE e source = raster, retorna também o SpatRaster recortado.Se TRUE e source = raster, retorna também o SpatRaster recortado.

RetornaRetorna

Um data frame com colunas code_muni, name_muni, abbrev_state, month, hour_local, hour_utc, ic_mean, ic_sd, noaa_class.

ExemplosExemplos

# Janeiro às 15h (tabela, rápido) hi_municipality("MOSSORO", state = "RN", month = 1, hour_local = 15) # Todos os meses e horas hi_municipality("MOSSORO", state = "RN") # Extração via raster (retorna SpatRaster também) hi_municipality("MOSSORO", state = "RN", month = 1, hour_local = 15, source = "raster", return_raster = TRUE)

hi_search()

Busca municípios no Semiárido Brasileiro por nome ou sigla de estado. Retorna o nome em maiúsculas no padrão IBGE a ser usado em hi_municipality().

ArgumentosArgumentos

ArgumentoArgumentoTipoTipoPadrãoPadrãoDescriçãoDescrição
namechrNome parcial ou completo do município. Sem distinção de maiúsculas.Nome parcial ou completo do município. Sem distinção de maiúsculas.
statechrNULLSigla do estado com duas letras para filtrar os resultados.Sigla do estado para filtrar os resultados.

RetornaRetorna

Um data frame com code_muni, name_muni e abbrev_state.

ExemplosExemplos

hi_search("Mossoro") hi_search("Campina", state = "PB") hi_search("a", state = "CE") # todos os municípios do Ceará
hi_plot()

Gera um mapa ggplot de um SpatRaster de Índice de Calor. Requer o pacote tidyterra.

ArgumentosArgumentos

ArgumentoArgumentoTipoTipoPadrãoPadrãoDescriçãoDescrição
xSpatRasterSpatRaster retornado por hi_download(), hi_municipality() ou hi_shape().
titlechr"Heat Index"Título do mapa.Título do mapa.
subtitlechrNULLSubtítulo do mapa. Se NULL, nenhum subtítulo é exibido.Subtítulo do mapa. Se NULL, nenhum subtítulo é exibido.
palettechr"continuous""continuous" ou "noaa".

RetornaRetorna

Um objeto ggplot.

ExemplosExemplos

r <- hi_download(month = 1, hour_local = 15) # Gradiente contínuo (padrão) hi_plot(r, title = "Índice de Calor, Janeiro 15h") # Com subtítulo personalizado hi_plot(r, title = "Índice de Calor para o Ceará", subtitle = "Média climatológica, Janeiro 15h local") # Paleta NOAA hi_plot(r, title = "Classificação NOAA", palette = "noaa")

hi_exposure()

Calcula a população exposta a cada classe NOAA do Índice de Calor para um dado mês e hora local, usando dados populacionais dos Censos IBGE (2000, 2010 ou 2022). Baixa uma tabela de ~35 MB do Zenodo no primeiro uso.Calcula a população exposta a cada classe NOAA do Índice de Calor para um dado mês e hora local, usando dados populacionais dos Censos IBGE (2000, 2010 ou 2022). Baixa uma tabela de ~35 MB do Zenodo no primeiro uso.

ArgumentosArgumentos

ArgumentoArgumentoTipoTipoPadrãoPadrãoDescriçãoDescrição
monthintMês (1-12). Obrigatório.Mês (1-12). Obrigatório.
hour_localint / chrHora local (0-23). Obrigatório.Hora local (0-23). Obrigatório.
census_yearint2022Ano do censo: 2000, 2010 ou 2022.Ano do censo: 2000, 2010 ou 2022.
bychr"municipality"Nível de agregação: "municipality", "state" ou "semiarid".
cache_dirchrNULLDiretório de cache.Diretório de cache.

RetornaRetorna

Um data frame com classe NOAA, contagem populacional e participação percentual. Colunas variam conforme o nível de agregação.Um data frame com classe NOAA, contagem populacional e participação percentual. Colunas variam conforme o nível de agregação.

ExemplosExemplos

# Total do Semiárido em janeiro às 15h hi_exposure(month = 1, hour_local = 15, by = "semiarid") # Por estado hi_exposure(month = 7, hour_local = 12, by = "state") # Por município com Censo 2000 hi_exposure(month = 1, hour_local = 15, census_year = 2000, by = "municipality")
